Writing and changing text

How to type, correct, undo, repeat and tidy text.

This chapter is about the text itself. It shows how to type it, take it out, change it in place, bring it back after a mistake, and do the same thing again without typing it again. It ends with the commands that tidy a whole block of lines: filling, sorting, spelling and recording keys. Chapter 2 shows how to get to the place you want to change, and chapter 4 shows what happens to the text you cut.

Keys are written as chapter 1 explains: C-x is Control and x, M-x is Alt and x, RET is Return, DEL is Backspace. The tables say "none" for a command that has no key and can only be run by name with M-x.

3.1 The two states

In NORMAL state the letter keys are commands. d deletes, u (non-modal: C-/) undoes, i starts typing. In INSERT state the letter keys write text. Most of your time goes to NORMAL state, where you choose what to change, and you go into INSERT state only to type. Figure 3.1 shows how the two connect.

The mode line says which state you are in. Each buffer keeps its own state, so a buffer you left in INSERT state is still in it when you come back to it.

Everything you type between the key that starts INSERT state and the key that ends it is one step for undo, line breaks included. If you type two lines and press u (non-modal: C-/), both go.

3.1.1 Commands for starting to type

ModalNon-modalCommandWhat it does
inonetuatara-insertStarts typing at the cursor. A selection, if there is one, is dropped first.
anonetuatara-insert-afterStarts typing after the character under the cursor.
Inonetuatara-insert-line-startStarts typing at the start of the line.
Anonetuatara-insert-line-endStarts typing at the end of the line.
ononetuatara-open-belowOpens a new line below this one and starts typing on it. A number first opens that many lines, with the cursor on the first.
Ononetuatara-open-aboveOpens a new line above this one and starts typing on it. A number first opens that many lines.
cnonetuatara-changeCuts the selection, or deletes the character under the cursor, and starts typing. See "Changing text" below.
C-g, ESCnonetuatara-normalIn INSERT state, goes back to NORMAL state. The selection is dropped, and a line you began and left blank loses the blanks that were put in to indent it.
noneC-g, ESCtuatara-quitThe key's command in the global map. In INSERT state it does the same as tuatara-normal, and in NORMAL state it drops the selection.

At the end of a line the cursor stands on the line break, so a types after it, at the start of the next line. A types at the end of the line you are on.

RET, DEL and <delete> change no text in NORMAL state, so you cannot spoil a file by leaning on them. TAB does nothing there either, except in the modes named by *tuatara-normal-tab-modes*, where it does what it does in INSERT state. tuatara-normal-return, tuatara-normal-inert and tuatara-normal-tab are the commands that stand behind those three keys. RET follows a link in an Org buffer and does nothing in a plain text buffer.

Typing the two keys of *insert-escape-keys* quickly one after the other leaves INSERT state too. The first goes into the text as soon as you press it, and is taken out again when the second follows within a fifth of a second. Typed more slowly, both letters stay. It works in ordinary editing buffers, but not in the minibuffer, a terminal or at several cursors.

With *modal-editing* set to nil, there are no states. Every buffer is always typing, letters write text, and all the other keys and commands in this chapter that start with Control or Meta still work.

3.2 Typing

In INSERT state a key that stands for a character puts that character in at the cursor. self-insert-command is the command behind that. A number before such a key puts the character in that many times, so C-u 20 = types a row of twenty equals signs.

Characters you type and delete one after another, in either state, join into one step for undo. After typing "weekend" and deleting the "d" with DEL, one u (non-modal: C-/) takes back all of it.

Try it, with a letter

  1. Press C-x C-f, type ~/letter.txt and press RET. The file is new, so the buffer is empty. Press i. The mode line shows TUATARA[I].
  2. Type Dear Hana,, press RET twice, then type Thanks for the weekend in Taupo. The weather was kind. Press RET and type Love, Aroha.
  3. Press DEL three times. The last letters of the name go.
  4. Press C-g. The mode line shows TUATARA[N] again. Press DEL once more. Nothing happens, because DEL changes no text in NORMAL state.
  5. Press u (non-modal: C-/). All the typing goes in one step and the buffer is empty again. Press U (non-modal: C-?) and all of it comes back.
  6. Press A to type at the end of the line. Type oha., which finishes the name again. Press C-g.
  7. Press C-x C-s to save.

3.3 Deleting

In INSERT state, DEL deletes the character before the cursor and C-d or <delete> the one after it. A letter with accents, or an emoji with a skin tone, goes as one character. A number first deletes that many, and a negative number deletes the other way. A Windows line end, a carriage return and a newline, counts as one.

In NORMAL state d does the same job and also works on a selection. Without a selection it deletes the character under the cursor. It keeps no copy, because a character under the cursor is a slip being corrected and not a cut. With a selection it cuts the text into the kill ring, which chapter 4 describes. A number before d deletes that many characters.

There is no command that deletes a word in one key. In NORMAL state press m w (non-modal: C-z m w) to select the word at the cursor, which chapter 5 explains, and then d. Press m w again before d to take one more word. M-z cuts up to the next character you name.

Where a fold hides text, a delete never removes what you cannot see. The fold opens first, and the same key pressed again deletes.

3.4 Changing text

c is delete and type in one key. With a selection, it cuts the selection and starts INSERT state. Without one, it deletes the character under the cursor and starts INSERT state. A line selection keeps its final line break, so what you type takes the place of the line's words and the line stays a line. The cut and what you type after it are one step for undo, so u (non-modal: C-/) puts back the old text whole.

To replace a word, select it with m w (non-modal: C-z m w), press c, type the new word and press C-g. To replace the end of a line, press D (non-modal: C-k) and then A and type. p with a selection pastes the kill ring over it, and chapter 4 describes it.

Try it, with a recipe

  1. Press C-x C-f, type ~/pancakes.txt, RET. Press i and type the lines Pancakes, eggs, milk, flour, each ended with RET except the last. Press C-g.
  2. The flour should come before the milk. The cursor is on the last line. Press C-x C-t. The flour line and the milk line trade places.
  3. Press g g (non-modal: M-<) to go to the top, then M-u. The title becomes PANCAKES. Press u (non-modal: C-/) and it is Pancakes again.
  4. Press j (non-modal: C-n) to go to the eggs line. Press d. The first letter goes. Press .. The next letter goes. Press u twice.
  5. Press g h (non-modal: C-a) to go to the start of the line, then C-u 3 d. Three letters go. Press u.
  6. On the eggs line press g j. The flour line joins the eggs line, with one space between. Press u.
  7. Press g g j A, type , large, and press C-g. Press g g and m w c, type Thin pancakes and press C-g. The title changes in one step.
  8. Press C-x C-s to save.

3.5 Undo, redo and repeat

Every change can be undone, back to the file as you opened it. Nothing is let go unless you set *undo-limit*. Undo also covers work Tuatara does in the background. A replacement or a sort of a large file is one step, and it stands where you gave it: while it runs you can keep typing, and u (non-modal: C-/) takes back your edits first and then the background job.

3.5.1 Commands

ModalNon-modalCommandWhat it does
uC-x u, C-/, C-_undoUndoes the last change. In a narrowed buffer a change outside the part shown is undone too, and the echo area says so.
UM-_, C-?, C-M-_redoRedoes the last change you undid. The cursor goes after the text that comes back.
.C-x zrepeatRuns the last command again, with the number it had.
noneC-uuniversal-argumentStarts a number for the next command. See "Repeat counts".

u and U (non-modal: C-/, C-?) work in NORMAL state. The other keys work in both states.

repeat is the key for "do that again". If the last command acted on a selection, the selection is made again first, as large as before, from the cursor. It is the same number of whole lines, or characters, or the same kind of text piece, or the same size of rectangle. After V J d deletes two lines, . deletes the next two. Pressing . again runs the command once more (without the modal layer, z after C-x z does). It repeats one command only, so for a longer run of keys, record them (see "Recording keys").

A number given to . replaces the one the command had. After C-u 3 d, a plain . deletes three characters again, and C-u 5 . deletes five.

3.5.2 Settings

SettingDefaultWhat it changes
*undo-limit*nilThe most memory, in bytes, that one buffer's undo history may hold. nil keeps every change. With a limit, the oldest changes go first, down to about three quarters of it, and never the newest.

3.6 Repeat counts

A number before a command makes it act that many times, or on that many things. Type C-u, then the digits, then the command: C-u 3 d deletes three characters and C-u 12 M-u puts twelve words in capitals. C-u alone means 4, C-u C-u means 16, and C-u - before a command gives it a negative number. While you type the number, the echo area shows it.

Each command in this chapter says what its number does. A command whose entry says nothing about a number does not use one.

3.7 Special characters

C-q reads the next key and puts in the character it stands for, whatever that key does otherwise. C-q TAB puts in a real tab character. C-q C-l puts in a form feed, the character that ends a page, and C-q RET puts in a carriage return. A number first puts the character in that many times.

For letters your keyboard lacks there are three ways. You can type a character by its Unicode name with C-x 8 RET, by a digraph (two keys that stand for one character) with C-x 8 &, or by an input method that changes what keys type while it is on.

Try it, with a card for a friend in Sweden

  1. In ~/letter.txt, press g e to go to the end, then o to start a new line. Type Greetings from Akaroa and press C-g.
  2. Press C-x 8 RET, type em dash and press RET. The dash is put in at the cursor.
  3. Press C-x 8 &, then e and '. An é goes in.
  4. Press C-x RET C-\, type swedish-postfix and press RET. Press i and type smaaland. The word reads småland. Press C-g.
  5. Press C-\ to turn the method off and C-\ again to turn it on.
  6. Press C-x 8 - to turn the method off.

3.8 Indentation and filling in plain text

TAB in plain text goes on to the next tab stop, which is every four columns as standard. Spaces are put in unless you ask for tab characters. In a language mode TAB indents the line as the language does, which chapter 13 describes.

Filling re-flows a paragraph so that no line is longer than the fill column, which is 80 as standard. The words stay in order, and the text that starts each line (an indent, a > for a quotation, a comment mark) is kept. Each item of a list is filled as a paragraph of its own, and its lines go on under its words, past the mark and any check box: - [ ] a task continues six columns in.

3.9 Spelling

3.10 Sorting and tidying lines

These commands work on the lines a selection touches. Without a selection they do nothing and say so. A large selection is handled in the background, so Tuatara never waits on it. With a number, a sort runs in descending order.

Try it, with a shopping list

  1. Press C-x C-f, type ~/shopping.txt, RET. Press i and type the lines milk, eggs, bread, eggs, butter, each ended with RET except the last. Press C-g.
  2. Press g g (non-modal: M-<), then V and J four times to select all five lines.
  3. Press M-x, type sort-lines and press RET. The list reads bread, butter, eggs, eggs, milk.
  4. Select the five lines again with g g, V and J four times, as the sort ended the selection. Press M-x, type delete-duplicate-lines and press RET. The second eggs goes, and the echo area says one line was deleted.
  5. Press u (non-modal: C-/) twice to get the original list back.
  6. Select the lines again, run flush-lines, type e and press RET. Every line with an e in it goes, so only milk is left. Press u.

3.11 Recording keys

When you want the same few keys on line after line, record them once and play them back. C-x ( starts recording, C-x ) stops, and C-x e plays the keys as if you had pressed them again. What you type in answer to a question is recorded too, so a search for a word searches for the same word each time. The mouse is not recorded, and a passphrase is never recorded. A play stops where a passphrase was typed and leaves that question to you. While you record, the mode line shows Rec.

A number before C-x e plays that many times, and 0 plays until a play fails. A play fails when a command in it fails, a search finds nothing or a move cannot go on. e pressed straight after a play plays once more, and again, until you press another key. Each play is one step for undo. A long run shows its progress in the mode line as Played 120/300, and C-g stops it between two plays. C-g while recording gives the recording up, and the keys recorded before it are kept. In INSERT state the first C-g only leaves INSERT state.

Try it, with a numbered list of birds

  1. Press C-x C-f, type ~/birds.txt, RET. Press i, type kea, RET, weka, RET, kiwi, RET, takahe, RET, kaka. Press C-g, then g g.
  2. Press C-x (. Press M-x, type insert-keys-counter, press RET. Then press i, type a full stop and a space, press C-g, then C-n and C-a, and press C-x ).
  3. The first line now begins with 1. =. Press ~C-u 4 C-x e~. The other four lines are numbered. The last play meets the end of the buffer when it moves down, so the echo area says =Stopped after 3 of 4 plays: End of buffer, but the number is already in.
  4. Press u (non-modal: C-/) four times. The four plays are taken back one at a time.
