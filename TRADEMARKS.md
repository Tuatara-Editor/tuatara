# The name Tuatara

Tuatara™ is the name of this editor, and the name and its logo are Michael
A Jones's trade marks. This page says how you may use them. It covers the
name only: the code is free software under the GNU General Public License,
version 3 or any later version, and nothing here takes away any right that
licence gives you.

The licence gives no rights in the name. As its section 7(e) allows, the
licence of Tuatara is given without any right to use the name Tuatara or its
logo as a trade mark.

## What you may do without asking

- Copy and hand on Tuatara as it is released, unchanged, under its own name:
  a copy of a release, a package for a distribution built from a release's
  sources, a mirror.
- Build Tuatara from its sources with only the changes a distribution needs to
  build and install it (paths, the build's flags, patches that fix a fault and
  are offered back), and call the result Tuatara.
- Write about Tuatara, teach it, review it, and name it when you say what your
  own work does: "a package for Tuatara", "a theme for Tuatara", "works with
  Tuatara", "based on Tuatara".
- Name a package for Tuatara `tuatara-NAME`, as long as its description does
  not say it comes from the Tuatara project when it does not.

## What needs another name

A changed version of Tuatara that you hand on to others, a fork, takes a name
of its own, one that is not Tuatara and could not be taken for it. You may say
it is based on Tuatara. Its about page, its window title and its packages then
use its own name and logo, not Tuatara's.

The same holds for a service or a product that would lead people to think it
comes from the Tuatara project when it does not.

## Asking

To use the name or the logo in another way, open an issue in the Tuatara
repository and ask. A yes is given in writing, for the use asked about.
