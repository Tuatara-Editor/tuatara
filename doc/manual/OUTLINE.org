#+title: Tuatara manual: chapters

Each chapter covers every command, setting and face of its subject, with its
keys and defaults. The last two list every name, generated from the
source.

tools/manual-tables.sh fills the tables into doc/manual/generated/, read in
Tuatara. tools/manual-html.sh makes the web pages and tools/manual-pdf.sh the
PDF, both in build/manual/. The web pages are a page for each chapter and
all.html, every chapter on one page, to print at once or search with the
browser's find. A button changes between light and dark colours, and a link
in the corner of each page opens the contents page. tools/manual-publish.sh REMOTE puts the pages on
the branch gh-pages of REMOTE, which GitHub Pages serves, at each release.
